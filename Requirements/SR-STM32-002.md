ID: SR-STM32-002
Title: Can Comunication Subsystem Requirement
Type: Functional
Priority: High
Source: Stakeholder

Description:
The system shall send and receive data, using the STM32 can module, and provide a mechanism for error handling. The communication protocol used is CAN.

Rationale:
Accurate and timely data exchange is essential for the operation of the system. The CAN protocol provides robust communication capabilities that are suitable for this requirement. Error handling is critical to ensure reliable data transmission.

Parent Requirement:
- HSR-STM32


Related Components:
- STM32 Microcontroller 1
- Raspberry pi 5

Verified By:
- IT-STM32-002
- ST-STM32-002

Verification:
Integration Test, System Test


Acceptance Criteria:
- The STM32 can module shall be configured to operate at a baud rate of 500 kbps.
- The system shall send data packets every 100 ms.
- The system shall receive and process incoming CAN messages.
- Error handling mechanisms shall be implemented to detect and respond to communication errors.
